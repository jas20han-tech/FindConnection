# GraphRAG Intelligence Platform

An enterprise-grade Graph RAG workspace: PDF ingestion builds a verified knowledge graph,
Personalized PageRank retrieves multi-hop context in milliseconds, and a WebGL canvas makes
every citation inspectable.

> **Status: Phase 1–5 complete (demo mode).** Ingestion, PPR retrieval, path finding, cascade
> simulation, temporal slices, SSE streaming and the WebGL workspace are implemented and
> verified end-to-end. Production-engine validation and scale benchmarking remain — see
> `docs/PROJECT_CONTEXT_TRACKER.md`.

---

## Quickstart (no Docker, no API key)

```powershell
# Backend (Python 3.12 via uv)
cd backend
uv venv --python 3.12
uv pip install -e ".[llm,pdf,graph,jobs,postgres]"
uv run uvicorn app.main:app --reload --port 8000

# Frontend (Node 20+)
cd frontend
npm install
npm run dev
```

Open http://localhost:3000. Demo mode is on by default:

* the API serves a seeded 39-node / 55-edge AI-ecosystem graph in 6 clusters (Neo4j not required);
* ingestion uses a deterministic extractor (OpenAI key not required);
* narratives are generated by a local grounded synthesizer;
* **every upload replaces the previous graph** — the newest document owns the canvas, so uploading
  `report-b.pdf` discards the nodes and documents from `report-a.pdf` instead of merging them; the
  ingestion panel reports the new totals and the snapshot is saved to
  `backend/data/runtime_graph.json` (`POST /api/v1/graph/reset` restores the seed);
* **nodes are coloured by source document** by default: each document gets its own colour family and
  the community picks the tint inside it, so clusters stay readable. `Type`, `Cluster` and `Rank`
  encodings are still one click away in the Layer panel;
* every panel, mode and canvas interaction is live.

### Enable the real engines

```powershell
Copy-Item .env.example .env
# set OPENAI_API_KEY=sk-... and DEMO_MODE=false
docker compose up --build
```

This starts Neo4j 5.26 (APOC + GDS), PostgreSQL 16, Redis 7, ChromaDB, FastAPI,
a Celery worker and the Next.js frontend.

## Architecture

```
Next.js 15 (Sigma.js WebGL + worker physics)
        │  HTTP + SSE
FastAPI ─┴─ Celery/Redis ── ingestion pipeline
        │                   PyMuPDF → token chunks → GPT-4o-mini structured
        │                   output → 3-tier resolver → Cypher UNWIND + vectors
        └── reasoning        intent router → PPR → paths / cascade / temporal
                             → streaming grounded synthesis
Storage: Neo4j 5.26 · PostgreSQL 16 · Redis 7 · ChromaDB
```

| Layer | Choice |
| --- | --- |
| API | FastAPI 0.115+, native SSE |
| Graph | Neo4j 5.26 (constraints + full-text + batch UNWIND) |
| Vectors | ChromaDB (`text-embedding-3-small`, 1536-dim) |
| Jobs | Celery + Redis, live telemetry in Redis |
| Files/state | PostgreSQL 16 (jobs, snapshots) |
| Frontend | Next.js 15, React 19, TypeScript, Tailwind, Zustand |
| Canvas | Sigma.js v3 + Graphology, ForceAtlas2 web worker |
| Simulation | NetworkX in-memory cascade analysis |

## API

| Method | Path | Purpose |
| --- | --- | --- |
| `POST` | `/api/v1/upload` | Upload a PDF / text / Markdown / CSV (415 for other types), returns `job_id` + SSE URL |
| `GET` | `/api/v1/upload/{job_id}/status` | Job snapshot (includes `nodes_added` / `edges_added` / `document_count`) |
| `GET` | `/api/v1/upload/{job_id}/stream` | SSE ingestion telemetry |
| `GET` | `/api/v1/graph/viewport` | Backbone graph |
| `GET` | `/api/v1/graph/node/{id}/neighbors` | Ego network |
| `GET` | `/api/v1/entity/search?q=` | `@Entity` autocomplete |
| `GET` | `/api/v1/graph/temporal?year=` | Time-slice diff |
| `POST` | `/api/v1/graph/reset` | Drop ingested data, restore the seed graph (memory backend) |
| `POST` | `/api/v1/simulate/impact` | In-memory node severance |
| `POST` | `/api/v1/query/stream` | SSE `graph_context` → `token` → `complete` |
| `POST` | `/api/v1/query` | Non-streaming answer |
| `GET` | `/health` | Component health |

Interactive docs: http://localhost:8000/docs
